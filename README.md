# B站缓存视频转 MP4

B站客户端缓存的视频是 .m4s 和 .blv 格式，只能在B站 App 里播放，投屏投不了，导出导不了，换个设备就没了。

之前用 Python 代码跑通过一次，但每次要开命令行、还要单独下载 ffmpeg，太麻烦了。

所以做了一个安装包版本，装完直接用。

## 功能

- 自动扫描B站缓存目录，列出所有可转换视频
- 支持批量转换，勾选要转的，一键搞定
- 支持三种缓存格式：video.m4s + audio.m4s（新版分离音视频）、单个 .m4s 文件、.blv 分段文件（老版格式）
- 已转换的自动跳过，不重复处理
- 实时进度条，显示当前在转哪个、成功/跳过/失败统计
- 转完一键打开输出目录

## 优势

**零依赖**：不需要装 Python，不需要单独下载 ffmpeg，不需要配环境。安装包里全部内置了，97MB 的 ffmpeg 直接打包进去。双击安装，打开就能用。

**高质量输出**：视频转 H.264，音频转 AAC 192kbps，分辨率帧率不变。转出来的 MP4 任何播放器都能播。

**100% 本地**：所有转换在自己电脑上完成，不上传任何东西，不需要联网。

## 怎么用

1. 下载安装包，双击安装
2. 打开软件
3. 填入B站缓存目录（在B站客户端 设置 - 下载设置 里能看到路径）
4. 填入输出目录（MP4 保存到哪里）
5. 点扫描，列出所有视频
6. 勾选要转的，点转换
7. 等进度条走完，去输出目录看结果

## B站缓存目录在哪

打开B站客户端，设置，下载设置，查看下载路径。

目录结构一般是：

```
download/
├── av号 或 bv号/
│   ├── entry.json
│   ├── video.m4s
│   └── audio.m4s
```

## 技术栈

- Electron 桌面框架
- Express 本地 API
- ffmpeg 音视频转码（内置）
- Node.js 后端逻辑

## 安装

从 Releases 下载安装包即可。

源码运行：

```bash
npm install
npm start
```
