# B站缓存视频转 MP4

> 一键将哔哩哔哩客户端缓存的视频转换为通用 MP4 格式，任何播放器都能播放。

## 为什么需要这个工具？

哔哩哔哩客户端缓存的视频使用私有格式（`.m4s` / `.blv`），**只能在 B 站 App 里播放**，无法用其他播放器打开，也无法编辑、投屏或分享。

本工具帮你把这些缓存视频**批量转换为标准 MP4**，转换后可以：
- 用任意播放器播放（PotPlayer、VLC、Windows Media Player...）
- 投屏到电视
- 导入视频编辑软件
- 传输到其他设备

## 软件优势

### 零依赖，装完即用
- **不需要安装 Python、ffmpeg 或任何运行时**
- 安装包已内置所有依赖（包括 ffmpeg）
- 双击安装，打开就能用

### 批量转换，一键搞定
- 自动扫描 B 站缓存目录，识别所有可转换视频
- 支持**全选/勾选**批量转换
- 已转换的视频自动跳过，不重复处理

### 支持多种缓存格式
| 格式 | 说明 | 支持 |
|------|------|:----:|
| video.m4s + audio.m4s | 新版分离音视频 | ✅ |
| 单个 .m4s 文件 | 单文件缓存 | ✅ |
| .blv 分段文件 | 老版格式 | ✅ |

### 高质量输出
- 视频编码：H.264（最高兼容性）
- 音频编码：AAC 192kbps
- 分辨率、帧率保持原始不变
- MP4 容器 + faststart 标记（支持网络串流）

### 实时进度显示
- 转换进度条实时更新
- 显示当前正在处理的视频标题
- 成功 / 跳过 / 失败 统计

### 100% 本地运行
- 所有操作在本地完成，不上传任何数据
- 不需要联网
- 保护你的隐私

## 使用方法

### 1. 下载安装
从 [Releases](../../releases) 下载最新版安装包，双击安装。

### 2. 打开软件
启动「B站缓存转MP4」。

### 3. 设置目录
- **缓存目录**：B 站客户端的下载目录，通常在：
  - `E:\视频bili\download`（自定义路径）
  - `C:\Users\用户名\AppData\Local\哔哩哔哩\download`（默认路径）
- **输出目录**：MP4 文件保存位置，随便选一个。

### 4. 扫描 → 转换
1. 点击「🔍 扫描视频」
2. 勾选要转换的视频（默认全选）
3. 点击「▶ 转换选中」
4. 等待完成，点击「📁 打开输出目录」查看结果

## B站缓存目录在哪？

打开 B 站客户端 → 设置 → 下载设置 → 查看「下载路径」。

目录结构一般是：
```
download/
├── av号 或 bv号/
│   ├── entry.json          ← 视频元信息（标题等）
│   ├── video.m4s           ← 视频流
│   └── audio.m4s           ← 音频流
```

## 技术栈

- **Electron** — 桌面应用框架
- **Express** — 本地 API 服务
- **ffmpeg** — 音视频转码引擎（内置，无需安装）
- **Node.js** — 后端逻辑
